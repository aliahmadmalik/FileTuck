# FileTuck 2.0.1

- Release source code, documentation, and original artwork under Apache-2.0.
- Add F-Droid store descriptions, icon, and changelogs.
- Increase version code to 7; file-saving behavior is unchanged.

This is a source release for F-Droid packaging. No new developer-signed APK is
attached. The existing GitHub 2.0 APK remains available. F-Droid has not yet
accepted or published the app.

Local release build and lint are checked before tagging. Device testing and
F-Droid-specific source scanning and build validation remain pending.
